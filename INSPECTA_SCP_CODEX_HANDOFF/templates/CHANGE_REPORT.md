# Engineering change report
## Identity
Run, task, parent/candidate artifact hashes, rule/model/tool/policy versions, change request and approval scope.

## Intended change
Source requirements and authorized architectural/behavioral delta. State what must remain unchanged.

## Actual change and traceability
Source -> requirement -> model/contract -> implementation -> tests/proofs -> packaged artifact. Link verbalized decision, target bindings and repair episode when applicable.

## Validation
List each mandatory gate, input identity, actual command/operation, result, valid/rejected tests, diagnostics, and evidence artifact. UNKNOWN/NOT_RUN are not pass.

## Budget and outcome
All attempts and child usage, remaining allowance, time categories, whether capped, and accepted/provisional status.

## Review and attestation
Record decisions/signature references only after actual approval. Verification of identity/integrity is not proof of requirement truth.
