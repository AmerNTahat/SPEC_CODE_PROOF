# Implementation progress

## Milestone ID — state

Achieved:
Record concrete implemented behavior.

In progress:
Record the current step.

Remaining:
List outstanding work and acceptance checks.

Evidence:
Commands, results, file references and hashes.

Budget:
Measured build/demo/run usage, reported separately; limitations visible.

Blockers / approvals:
State the real blocker and exact recovery action.

Use scripts/report_milestone.py to append comparable records. Do not mark a milestone complete solely because documentation was written.
