## Conflict resolution
Current user instruction > this decision record > consolidated goal > focused milestone goals > examples/templates > archive. Security and genuine authorization boundaries always remain enforced. Record real conflicts before proceeding; do not invent a resolution that relaxes acceptance.

## Avoid two traps
A 'hard token cap' requires demonstrable enforcement by the selected adapter. Streaming or post-turn usage alone may be best-effort. Strict mode blocks paid execution when the advertised guarantee cannot be provided; an explicitly authorized best-effort mode reports the limitation.

A published 'latest' image is not proof every tool is latest. Use current documentation to check required capabilities, honor the user-selected versions, test as a combination, and record digest/revisions. A modern reference environment does not automatically reproduce the historical DASC setup.
