# Frozen-knowledge transfer protocol
Freeze source manifests, approved rule release, extraction/retrieval policy, common documentation, toolchain/model configuration, budget and allowed diagnostics. Audit all solution-bearing files and prior development usage.

For each target/condition, create an independent restricted workspace and fresh Codex session. Do not carry learning session IDs, inherited memory, source-specific completed solutions, unapproved skills/config, repository history, or golden-reference indexes. A Git worktree alone is not source-history isolation.

Rule-only transfer still receives target requirements and common tool documentation. Source-retrieval and token-matched summary conditions receive their explicitly declared additional material. Keep allowances comparable and record actual context usage.

Generate/repair under the same policy in all conditions. Run the declared ordinary tool feedback in-loop; hidden-reference evaluation remains out-of-loop. At the end, evaluate the frozen artifact independently. No target learning/revised rule publication occurs until the final study's protected boundary permits it; later examples used for learning are no longer held out for that release.

Retain every attempt and cost. Repeat important comparisons and group results by independent task family. Distinguish cross-subsystem, cross-system, cross-toolchain, and cross-model transfer. No new model/fine-tuning is part of this initial protocol.
