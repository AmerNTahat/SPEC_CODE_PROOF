# Demonstration script — execute after the relevant milestones
## Preparation
Resolve actual source checkouts, review the requirement ledger and target architecture, configure data permissions/model/profile/budget, run setup checks, and lock the environment. Do not place evaluator truth inside the agent workspace. The starter configs are draft, not ready-to-run source models.

## Isolette guided story
1. Open the Workbench or equivalent CLI; select Learning and inspect source/development directories.
2. Show an approved source obligation and Astra's trigger/semantic choice/placement/repair-gate record.
3. Show the abstraction, a task-specific binding and a contrasting incompatible case; distinguish source-stated versus inferred content.
4. Record the combined rulebook confidence question/forecast before evaluation.
5. Generate/apply within budget; show a real check failure and tool evidence.
6. Demonstrate automatic permitted repair. In a separate checkpoint, demonstrate a human suggestion in Interactive mode.
7. Inject an architecture-breaking change to show independent rejection. Remove it through a valid scoped repair; recheck all affected evidence.
8. Review evidence and approve the rule release. User Mode applies it frozen to an authorized task with a fresh session.
9. Inspect requirements, architecture, GumboX/formal-tool results as applicable, traceability, total usage and unresolved checks.
10. Package/sign the accepted scope; run independent verification; deliberately modify a copied artifact and demonstrate rejection.

## KSU follow-ups
Producer/Consumer exercises event-data semantics and rules' applicability. Network Guard exercises filtering/composition and independent/manual/GumboX tests. Treat completed source examples as development/regression unless genuinely excluded and audited for transfer.

## Replay
Save a real event stream only after a real run. Label replays and fault-injection cases; never substitute synthetic good numbers. A presenter may inspect cached results without new paid calls. Keep sensitive source/test data out of public recordings.
